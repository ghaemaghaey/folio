## Task 3: Cross-Device EPUB Position Matching

**Problem:** EPUB has 260 pages on desktop, 370 on mobile. Page numbers don't translate. Need content-based position matching.

**Approach: Character Offset + Text Fingerprint**

### Position Format Change

Current: `{ p: <page>, c: <chapter>, s: <subPage>, sc: <scrollRatio> }`

New for EPUB: `{ c: <chapter>, co: <charOffsetFraction>, fp: <textFingerprint> }`
- `c` — chapter index (stable across devices)
- `co` — character offset as fraction 0.0-1.0 through the chapter's text (content-based, not viewport-based)
- `fp` — 8-char text fingerprint from the content at the current position (for verification)

PDF stays the same (page numbers are stable for PDF).

### How it works:

**On save (close):**
1. Get current chapter index
2. Walk DOM text nodes in the chapter to find the character at the viewport's top edge
3. Count total characters in the chapter
4. `co = charOffset / totalChars` (0.0 to 1.0)
5. Extract 8 chars of text at that position as fingerprint

**On restore (open):**
1. Get the chapter's text content
2. Find the character at position `co * totalChars`
3. Find the nearest element containing that text
4. Scroll to that element

### Files to modify:
- `desktop/frontend/dist/main.js` — serializePosition, openBookId restore, closeReader save
- `android/app/src/main/assets/www/main.js` — same changes
- Server position format is just a string — no schema change needed

## Task 4: Device Name from OS Model

**Problem:** Random IDs like `Android-k7f2x9pq` are meaningless. User wants "Poco X3 Pro", "HP Laptop" etc.

### Android:
Expose `Build.MANUFACTURER + Build.MODEL` via the JS bridge.

**File:** `android/app/src/main/java/com/folio/reader/MainActivity.kt`
Add a method callable from JS:
```kotlin
@JavascriptInterface
fun getDeviceModel(): String {
    return "${android.os.Build.MANUFACTURER} ${android.os.Build.MODEL}"
}
```

**File:** `android/app/src/main/assets/www/main.js`
Update `getDeviceName()`:
```js
function getDeviceName() {
  // Try to get real model from Kotlin bridge
  if (typeof FolioAndroid !== "undefined" && FolioAndroid.getDeviceModel) {
    const model = FolioAndroid.getDeviceModel();
    if (model) return model;
  }
  // Fallback
  let id = localStorage.getItem("folio.deviceId");
  if (!id) {
    id = Math.random().toString(36).slice(2, 10);
    localStorage.setItem("folio.deviceId", id);
  }
  return `Android-${id}`;
}
```

### Desktop:
Use `navigator.userAgent` to extract a recognizable name, or expose via Wails.

**File:** `desktop/frontend/dist/main.js`
Update `getDeviceName()`:

function getDeviceName() {
  const ua = navigator.userAgent || "";
