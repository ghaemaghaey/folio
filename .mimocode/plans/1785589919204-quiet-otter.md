# Fix: Device Name Mismatch Breaks Same-Device Detection

## Problem
Old positions stored as "Android-k7f2x9pq" (random ID) don't match new name "Xiaomi Poco X3 Pro" (real model). The `d.device !== currentDevice` comparison fails, treating same-device as cross-device.

## Fix
Normalize device names to platform keywords before comparison:
- "Xiaomi Poco X3 Pro" → "android"
- "Android-k7f2x9pq" → "android"
- "Windows PC" → "windows"
- "Desktop-a3f8k2m1" → "desktop"

### Files:
- `android/app/src/main/assets/www/main.js` — openBookId
- `desktop/frontend/dist/main.js` — openBookId
