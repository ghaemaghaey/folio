# Fix: Sync Only on Explicit Exit

## Problem
The debounced sync in `flushProgress` (every 30 seconds) doesn't work reliably on Android. User wants sync only when explicitly exiting the book (back/close button).

## Fix
1. Remove debounced sync from `flushProgress` (both platforms)
2. Add explicit `syncProgressToServer` in `closeReader` after `flushProgress()`
3. Add explicit sync in the back button handler

### Files:
- `android/app/src/main/assets/www/main.js`
- `desktop/frontend/dist/main.js`
