# Remove Build on Push to Main

## Problem

`ci.yml` runs on every push to main (merged PRs). These builds produce no release and are wasted CI minutes. When a release is needed, `release.yml` rebuilds everything anyway via tag push.

## Fix

Change `ci.yml` to only run on PRs (for validation), not on push to main.

### File: `.github/workflows/ci.yml`

Change:
```yaml
on:
  push:
    branches: [main, master]
  pull_request:
    branches: [main, master]
```

To:
```yaml
on:
  pull_request:
    branches: [main, master]
```

## Result

- PRs still get validated (vet, smoke test, build)
- No wasted builds on merge to main
- Tag push triggers `release.yml` + `android.yml` + `server-image.yml` for actual releases
