# Fix Book Thumbnails/Covers

## Problem

1. **EPUB covers don't show** (desktop + Android) — just shows book name text
2. **Only one PDF thumbnail on Android** — other PDFs don't show covers
3. **OPDS-downloaded books lose their cover** — cover URL not saved to library

## Root Causes

1. **No EPUB cover extraction** — `epub.go` (desktop) and `EpubBook.kt` (Android) never parse the OPF `<meta name="cover">` or `properties="cover-image"` manifest item. No cover image is ever extracted from the EPUB zip.

2. **OPDS books downloaded without covers** — When a book is downloaded from OPDS, the `coverURL` (HTTP URL from Calibre) is not saved to the library `Book` struct. Only generated on open (PDF only).

3. **Android PDF renderer is single-document** — Background cover threads for multiple PDFs may race. But disk cache should handle this — the real issue is likely that covers are only generated on first open, and if the user has many books, only the ones they've opened get covers.

## Fix 1: EPUB Cover Extraction (Desktop)

### File: `desktop/internal/epub/epub.go`

Add cover image detection to the OPF parser:

1. In `parseOPF` (around line 564), after parsing metadata:
   - Check for EPUB2: `<meta name="cover" content="cover-image-id"/>`
   - Check for EPUB3: `<item properties="cover-image">` in manifest

2. Add a `CoverImagePath` field to the `Book` struct (line 15-22):
   ```go
   type Book struct {
       // ... existing fields ...
       CoverImagePath string // path inside zip to cover image
   }
   ```

3. In the OPF parser, when a cover item is found, store its `href` as `CoverImagePath`.

4. Add a method `ExtractCover() ([]byte, error)` that reads the cover image from the zip and returns the raw bytes.

### File: `desktop/app.go`

In `openEPUB` (around line 593), after parsing the EPUB:

1. Check if the book has no `CoverDataURL`
2. If cover image path exists, extract the image from the zip
3. Convert to JPEG if needed, resize to 48 DPI equivalent
4. Base64-encode as data URL
5. Save to library via `lib.Upsert()`

## Fix 3: Save OPDS Cover URL to Library

### File: `desktop/opds_app.go`

In the download handler (around line 535), when creating the `library.Book`:
```go
CoverDataURL: entry.CoverURL,  // save the HTTP URL
```

Wait — `CoverDataURL` expects a data URL, not an HTTP URL. Instead, add a `CoverURL` field to the Book struct for external URLs, or fetch and convert the cover image.

**Better approach**: In the download handler, fetch the cover image URL (thumbnail), convert to data URL, and store it. This way covers work offline too.

### File: `android/app/src/main/java/com/folio/reader/AppFacade.kt`

Same — in the OPDS download flow, fetch the cover URL and convert to data URL before saving.
